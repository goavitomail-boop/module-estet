# Модуль Эстет — кухни и шкафы на заказ

Сайт https://module-estet.ru: каталог кухонь и шкафов, квиз-расчёт, запись
на замер, админка заявок, уведомления в MAX.

Next.js 16 · React 19 · Tailwind CSS 4 · Postgres (Neon) · Vercel Blob.

```bash
pnpm install
pnpm dev        # разработка, http://localhost:3000
pnpm build && pnpm start
```

Переменные окружения — `.env.example` (скопировать в `.env.local`, не коммитить).
