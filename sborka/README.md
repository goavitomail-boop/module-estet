# Сборка

Сервис «Сайт за 24 часа за 4 999 ₽»: клиент заполняет бриф, система собирает сайт, клиент смотрит прототип в личном кабинете и платит, только если сайт понравился.

- `docs/TECH_PLAN.md` — технический план проекта
- `docs/DECISIONS.md` — принятые решения: название, стиль, ниши, юр. статус, ИИ
- `DESIGN.md` — дизайн-система нашего сайта

## Запуск

Нужен Node.js 22.

```bash
cd apps/web
npm install
cp .env.example .env.local
npm run dev        # http://localhost:3000
```

Сборка для продакшена: `npm run build && npm start`. Проверка типов: `npm run typecheck`.

## Что уже работает

| Страница | Что делает |
|---|---|
| `/` | Лендинг: прелоадер, 3D-сборка сайта (three.js), свой курсор, бегущие строки, текст со скролл-подсветкой, счётчики, живая сборка по нишам, закреплённая горизонтальная галерея, карточка цены с наклоном |
| `/brief` | Бриф из 4 шагов с проверкой полей и согласием на обработку данных |
| `/order/<токен>` | Личный кабинет: прототип (компьютер / телефон), другие варианты, правки, оплата |
| `/preview/<токен>` | Прототип сайта клиента с водяным знаком (без знака после оплаты) |
| `/examples/<ниша>` | Примеры сайтов для портфолио: `nails`, `repair`, `auto`, `psychologist`, `coffee` |
| `/pay/stub/<id>` | Тестовая оплата вместо ЮKassa |

## Фото для шаблонов

Положите фото в `apps/web/public/images/niches/` с именами `<ниша>-hero.jpg` (4:5) и `<ниша>-about.jpg` (1:1), где ниша — `nails`, `repair`, `auto`, `psychologist`, `coffee`. Подходят `.jpg`, `.webp` и `.png`. Фото подхватываются автоматически: в примерах, в прототипах и в 3D-сцене первого экрана (`coffee-hero`). Пока фото нет, рисуются абстрактные композиции.

## Что пока заглушка

- **Генерация без ИИ.** `TemplateGenerator` (`src/lib/sites/generator.ts`) собирает сайт из шаблона ниши и ответов брифа. ИИ-провайдер подключается реализацией интерфейса `SiteGenerator`, остальной код не меняется.
- **Правки** сохраняются в заказ и пишутся в лог сервера; вносит их пока человек.
- **Оплата** — `PAYMENT_PROVIDER=stub`: деньги не списываются, «Оплатить» на тестовой странице сразу помечает заказ оплаченным. ЮKassa подключается реализацией `PaymentProvider` (`src/lib/payments.ts`).
- **Хранилище** — JSON-файл `apps/web/.data/db.json`. Перед запуском — PostgreSQL с тем же интерфейсом (`src/lib/store.ts`).
- **Вход в кабинет** — по секретной ссылке. Позже — вход по email или Telegram.
- **Уведомления** о заказах и оплатах пишутся в лог сервера (`notifyOwner`), позже — Telegram-бот.
- На сайте отмечены пунктирной рамкой данные, которые нужно заполнить: контакты, реквизиты, оферта, политика конфиденциальности, условия хостинга и доработок.

## Структура

```
apps/web/src/
├── app/                  # страницы и API (Next.js App Router)
├── components/landing/   # секции лендинга
├── lib/
│   ├── sites/            # схема сайта, ниши, темы, генератор
│   ├── store.ts          # хранилище заказов и платежей
│   ├── orders.ts         # создание заказа, лимиты правок и вариантов
│   └── payments.ts       # провайдер оплаты (заглушка)
└── sites/                # рендерер клиентских сайтов
```
