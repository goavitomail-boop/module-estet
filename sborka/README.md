# Сборка

Сервис «Сайт за 24 часа за 4 999 ₽»: клиент заполняет бриф, система собирает сайт, клиент смотрит прототип в личном кабинете и платит, только если сайт понравился.

- `docs/TECH_PLAN.md` — технический план проекта
- `docs/DECISIONS.md` — принятые решения: название, стиль, ниши, юр. статус, ИИ
- `DESIGN.md` — дизайн-система нашего сайта

## Запуск

Нужен Node.js 22.

```bash
cd apps/web
npm install
cp .env.example .env.local
npm run dev        # http://localhost:3000
```

Сборка для продакшена: `npm run build && npm start`. Проверка типов: `npm run typecheck`.

## Что уже работает

| Страница | Что делает |
|---|---|
| `/` | Лендинг: прелоадер, 3D-сборка сайта (three.js), свой курсор, бегущие строки, текст со скролл-подсветкой, счётчики, живая сборка по нишам, закреплённая горизонтальная галерея, карточка цены с наклоном , блок «Почему не конструктор» |
| `/brief` | Бриф из 6 шагов: сфера карточками, о бизнесе, услуги, «что будет на сайте» (что входит и что платно, с объяснением каждого пункта), куда присылать заявки, контакты и стиль. Внизу всегда итог заказа. Черновик сохраняется в браузере Справа — живое превью: сайт собирается тем же генератором (`/api/preview`) по мере заполнения и подъезжает к блоку текущего шага; на телефоне открывается кнопкой «Превью» |
| `/order/<токен>` | Личный кабинет. Сразу после брифа — экран «сайт собирается на глазах» из данных клиента (`?new=1`), затем экскурсия по прототипу: сайт листается к блокам, блок обводится рамкой, открывается окно записи, показывается версия для телефона. Прототип в настоящем масштабе (1440 и 390 px), варианты карточками со стилем, правки, оплата. Описание шагов — `src/lib/sites/presentation.ts` |
| Вкладки кабинета | «Заказ» — позиции, итог и оплата на эту сумму; «Изменить» — услуги и цены, тексты, контакты, блоки, команда, отзывы, цифры: сайт пересобирается сразу и прокручивается к изменению; «Добавить» — платные дополнения (фишки видно на прототипе), куда слать заявки, «не нашли нужное»; «Правки» — словами дизайнеру |
| Редактор на сайте | Кнопка «Редактировать на сайте» в кабинете: текст правится прямо на прототипе, по клику на фото — библиотека сферы и загрузка своего (сжимаем в WebP до 1800 px), над блоком — «↑ ↓ Скрыть», справа — главный цвет, шрифт заголовков, форма кнопок, вид первого экрана, «Отменить». Разметка в рендерере: `data-ek` (блок), `data-ef` (текст), `data-ei` (фото), `data-svc` (услуга); мост — `src/sites/EditBridge.tsx` |
| `/preview/<токен>` | Прототип сайта клиента с водяным знаком (без знака после оплаты) |
| `/examples/<ниша>` | Примеры сайтов для портфолио: `coffee`, `nails`, `repair`, `auto`, `psychologist`, `fitness`, `legal`, `barber`, `cleaning`, `dental`, `photo`, `florist`, а также `other` — универсальный шаблон «Другое» |
| `/pay/stub/<id>` | Тестовая оплата вместо ЮKassa |

## Фото и иконки в шаблонах

Фото лежат в `apps/web/public/images/niches/` с именами `<ниша>-<слот>.webp`: `hero`, `about`, `gallery-N`, `service-N`. Подходят `.jpg`, `.webp` и `.png`; фото подхватываются автоматически — в примерах и в прототипах. Пока фото слота нет, рисуется абстрактная композиция.

Сейчас там фото с лицензией CC0 (StockSnap и WordPress Photo Directory через Openverse) — список с авторами и ссылками в `public/images/niches/SOURCES.md`. Иконки — [Phosphor](https://phosphoricons.com) (MIT), толщину линии выбирает тема.

## Как устроен внешний вид сайтов клиентов

Тема (`src/lib/sites/themes.ts`) задаёт не только цвета и шрифты, но и характер сайта: композицию первого экрана (`hero`: фото справа, фото на весь экран, журнальная вёрстка, текст по центру, коллаж), вид шапки, толщину иконок, характер движения (`motion`: мягкий, элегантный, энергичный) и декор (бегущая строка, пятна цвета, линии сетки, вращающаяся печать, плашки с адресом).

Кроме темы, у каждой ниши свой «почерк» (`src/sites/signature.ts`), одинаковый для светлой и тёмной темы:

|---|---|---|---|
| Кофейня | пар над чашкой | витрина меню: фото сменяется при наведении | предзаказ с подсчётом суммы, полароиды, записки-отзывы |
| Маникюр | флаконы лака по орбите | подбор оттенка: ногти и флакон перекрашиваются | галерея-арки, отзывы по одному |
| Ремонт | чертёж рисует сам себя | калькулятор: вид ремонта × площадь | таймлайн этапов, вызов замерщика |
| Автосервис | луч фар и полосы скорости | точки на машине с ценами | горизонтальная галерея, отзывы бегущей лентой |
| Психолог | северное сияние | дыхательная практика | этапы стопкой, текст проявляется при прокрутке |
| Фитнес | кардиограмма | тест «какая тренировка подойдёт» | плёнка из фото, огромные номера этапов |
| Юрист | договор с подписью и печатью | навигатор по ситуациям | таймлайн, вопросы с номерами |
| Барбершоп | барберский столб и плёночное зерно | лукбук: огромный прайс с фото | выбор барбера в записи, курсор-инверсия |
| Клининг | мыльные пузыри | «проведите по фото — станет чисто» | отзывы перепиской, вопросы карточками |
| Стоматология | «жидкая» форма и блики | запись по шагам прямо на странице | этапы стопкой |
| Фотограф | шлейф из фото за курсором | просмотр фото во весь экран | колонки разной высоты, интро по буквам |

Кнопки записи на всех сайтах открывают всплывающее окно с шагами под нишу (`src/sites/interactive/Booking.tsx`); после первого экрана появляется плавающая кнопка. В примерах и прототипах заявка никуда не отправляется — окно честно об этом пишет.

Анимации (`src/sites/SiteMotion.tsx` и `site.module.css`): интро с названием компании, появление заголовков по словам, шторки на фото, параллакс, фото с цитатой, раскрывающееся на весь экран при прокрутке, горизонтальная галерея, этапы стопкой, текст «О нас», проявляющийся при прокрутке, счётчики, фото услуги у курсора, свой курсор и «магнитные» кнопки. Миниатюры на лендинге рендерятся без анимаций (`motion={false}`); при `prefers-reduced-motion` всё показывается сразу.

## «Другая сфера»

Если сферы нет среди двенадцати, клиент выбирает «Другое», пишет, чем занимается («автошкола», «ремонт телефонов»), и как к нему приходят клиенты: записываются на время, оставляют заявку или идут на консультацию. Универсальный шаблон (`src/lib/sites/niches/other.ts`) собирает из этого тексты, кнопки, этапы работы и вопросы-ответы, подбирает иконку по ключевым словам и предлагает четыре стиля: «Чистый», «Тёплый», «Смелый», «Премиум». Своих фото у шаблона нет — до загрузки фото клиента на их месте абстрактные композиции в цветах сайта.

## Дополнения и цены

Всё, что можно добавить к сайту, и цены — в `src/lib/addons.ts`: один источник для лендинга, брифа, кабинета и оплаты. Сумму к оплате считает сервер (`quote`), клиент её не передаёт. Настройки клиента поверх собранного сайта (скрытые блоки, свои тексты и фото по адресу поля, порядок блоков, оформление, команда, отзывы, цифры, платные фишки) применяет `src/lib/sites/customize.ts` к любому варианту, поэтому правки не теряются при смене варианта. Перед каждой правкой заказ запоминает прошлое состояние (последние 20) — так работает «Отменить».

## Что пока заглушка

- **Генерация без ИИ.** `TemplateGenerator` (`src/lib/sites/generator.ts`) собирает сайт из шаблона ниши и ответов брифа. ИИ-провайдер подключается реализацией интерфейса `SiteGenerator`, остальной код не меняется.
- **Правки** сохраняются в заказ и пишутся в лог сервера; вносит их пока человек.
- **Оплата** — `PAYMENT_PROVIDER=stub`: деньги не списываются, «Оплатить» на тестовой странице сразу помечает заказ оплаченным. ЮKassa подключается реализацией `PaymentProvider` (`src/lib/payments.ts`).
- **Хранилище** — JSON-файл `apps/web/.data/db.json`, фото клиентов — `apps/web/.data/uploads/`. Перед запуском — PostgreSQL с тем же интерфейсом (`src/lib/store.ts`).
- **Вход в кабинет** — по секретной ссылке. Позже — вход по email или Telegram.
- **Уведомления** о заказах и оплатах пишутся в лог сервера (`notifyOwner`), позже — Telegram-бот.
- **Заявки с сайтов клиентов** пока никуда не уходят: выбор «Telegram / MAX / почта» сохраняется в заказ, отправку делаем на этапе 2.
- **Платные дополнения без превью** (карты, YCLIENTS, онлайн-оплата, страницы, срочность) сохраняются в заказ и оплачиваются, подключает их пока человек.
- На сайте отмечены пунктирной рамкой данные, которые нужно заполнить: контакты, реквизиты, оферта, политика конфиденциальности, условия хостинга и доработок.
