# GOAvito — технический план

**Продукт:** сервис «Сайт за 4 999 ₽ за 24 часа». Клиент описывает бизнес → ИИ собирает сайт по нашему шаблону и промту → клиент смотрит прототип в личном кабинете → оплачивает → мы публикуем сайт на хостинге с его доменом.

---

## 1. Путь клиента

1. **Лендинг.** Клиент видит анимированный сайт, портфолио и живое демо: вводит «кофейня в Казани», и прямо в hero-блоке за несколько секунд собирается мини-сайт.
2. **Бриф (3–5 шагов, без регистрации):** тип бизнеса и ниша → выбор стиля из портфолио («хочу как этот») → название, услуги, цены, контакты, город → пожелания свободным текстом → загрузка логотипа и фото (необязательно).
3. **Регистрация в один клик:** вход по ссылке на email, через Telegram или по коду из SMS. Сразу после неё запускается генерация.
4. **Генерация (2–5 минут).** В кабинете виден прогресс: «пишем тексты → подбираем цвета → собираем страницы → проверяем мобильную версию».
5. **Прототип.** Сайт открывается по ссылке `preview.<наш-домен>/<id>` с водяным знаком. Клиент может:
   - бесплатно внести до 3 правок текстом («сделай темнее», «добавь блок с отзывами»): ИИ пересобирает сайт;
   - бесплатно сгенерировать до 2 альтернативных вариантов.
6. **Оплата 4 999 ₽** через ЮKassa (карта, СБП, SberPay), чек по 54-ФЗ формируется автоматически.
7. **Публикация.** Заказ попадает в админку → вы публикуете сайт и подключаете домен (позже это будет делаться автоматически) → клиент получает уведомление «Сайт опубликован».
8. **После публикации:** платные доработки, хостинг по подписке, допродажи (SEO, Яндекс.Карты, аналитика).

Обещание «24 часа» реалистично: генерация занимает минуты, остальное время уходит на ручную публикацию.

## 4. Генерация сайтов — сердце продукта

### Главный принцип: ИИ заполняет шаблон, а не пишет код с нуля

Если просить ИИ каждый раз писать весь HTML с нуля, качество будет «лотереей»: верстка ломается, мобильная версия плывёт, анимации тормозят. Надёжнее так:

1. **Библиотека секций.** Мы один раз вручную делаем 30–50 качественных секций: hero (5–7 вариантов), «о нас», услуги, цены, галерея, отзывы, FAQ, команда, контакты с картой, форма заявки, футер. Каждая секция — Astro-компонент с готовыми анимациями и адаптивом.
2. **Шаблоны.** Шаблон — это набор секций + дизайн-токены (шрифты, палитра, радиусы, стиль анимаций). Каждому шаблону соответствует **промт-образец** с правилами тона, структуры и стиля. Каждая работа в портфолио — это шаблон.
3. **ИИ возвращает JSON по строгой схеме:** какие секции и в каком порядке, все тексты, палитра (в рамках допустимых), подбор иконок и запросы для фото. Схема проверяется через structured outputs, так что «сломанный» ответ невозможен.
4. **Сборщик** подставляет JSON в шаблон и собирает статический сайт.
5. **Режим «свободная секция» (позже).** Для нестандартных пожеланий ИИ может сгенерировать одну секцию кодом. Она проходит отдельную проверку и запускается в изолированном iframe.

### Конвейер одной генерации

```
бриф клиента
  + промт-образец выбранного шаблона
  + описание библиотеки секций (кэшируется)
        │
        ▼
[1] ИИ: план сайта + тексты + палитра → JSON (строгая схема)
[2] Валидация: цвета (контраст WCAG), длина текстов, телефоны и ссылки
[3] Подбор фото: загрузки клиента → стоки (Unsplash/Pexels API) → ИИ-генерация
[4] Сборка Astro → статика
[5] Playwright: скриншоты 1440px и 390px; проверка, что ничего не вылезает за экран
[6] (опционально) ИИ смотрит на скриншоты и даёт правки → один повтор шагов 1–5
[7] Загрузка в S3, ссылка на превью, уведомление
```

Правка клиента («сделай темнее») — это тот же конвейер: на вход подаются текущий JSON и текст правки, на выходе получается новая версия. Все версии хранятся, к любой можно откатиться.

### Стоимость одной генерации

Цены Claude Opus 5.5: $4 за 1 млн входящих токенов и $20 за 1 млн исходящих. Повторяющаяся часть промта кэшируется.

| Шаг | Вход | Выход | ≈ Стоимость |
|---|---|---|---|
| Генерация JSON сайта | ~25k (большая часть из кэша) | ~10–15k (вместе с размышлением) | ~$0.35 |
| Визуальная самопроверка по скриншотам | ~10k | ~3k | ~$0.10 |
| **Итого за вариант** | | | **≈ $0.45 (~40–50 ₽)** |
| Худший случай: 2 варианта + 3 правки | | | **≈ $2.5 (~250 ₽)** |

Даже в худшем случае ИИ съедает ~5% от чека. Главная статья расходов — **бесплатные генерации тех, кто не заплатил**. Защита от злоупотреблений:
- генерация только после входа в аккаунт;
- лимит: 1 бесплатный проект на аккаунт или телефон, ограничение запросов с одного IP, капча на брифе;
- платная перегенерация сверх лимита (например, 299 ₽, засчитывается в оплату).

Если нужно дешевле, можно перевести генерацию на `claude-sonnet-5-5` ($2 / $10): это примерно в 2 раза дешевле. Решать лучше после сравнения качества на 20–30 тестовых брифах.

> ⚠️ **Важно проверить до старта:** Anthropic API официально недоступен для аккаунтов из России. Варианты: оформить API-аккаунт и оплату на юрлицо или ИП в поддерживаемой стране либо заложить в архитектуру возможность подключить другую модель (YandexGPT, GigaChat). Модуль генерации проектируем так, чтобы провайдера ИИ можно было заменить (интерфейс `SiteGenerator`).

## 5. Личный кабинет и защита прототипа

**Кабинет клиента:**
- список проектов и статус: «генерируется», «готов к просмотру», «оплачен», «публикуется», «опубликован»;
- превью сайта в рамке с переключателем «десктоп / телефон»;
- поле «Что изменить?» и история версий;
- кнопка «Оплатить 4 999 ₽»;
- после оплаты: форма данных домена (есть свой / помогите купить) и чат с поддержкой (или ссылка на Telegram).

**Защита прототипа от копирования до оплаты.** Полностью защитить HTML нельзя, но можно сделать копирование бессмысленным:
- водяной знак поверх сайта (CSS + canvas-оверлей) и плашка «Прототип GOAvito»;
- в превью нет рабочих форм, ссылки на соцсети и телефоны отключены;
- код минифицируется, изображения отдаются в уменьшенном размере с водяным знаком;
- превью открывается только по токену, срок действия ссылки — 14 дней.

## 8. Наш сайт: «мега-крутой и максимально анимированный»

### Концепция
Сайт сам демонстрирует продукт: **на глазах у посетителя сайт собирается из промта.** Это и есть главный «вау-эффект», и он продаёт лучше любых слов.

### Структура и анимации по блокам

| Блок | Что происходит |
|---|---|
| **Прелоадер** | Счётчик 0→100 и логотип, собирающийся из линий (SVG + GSAP DrawSVG/MorphSVG); переход шторкой в hero |
| **Hero** | WebGL-фон (шейдер «жидкий градиент», реагирует на курсор). Заголовок «Сайт за 24 часа. 4 999 ₽» появляется по буквам (SplitText). Справа — «живой терминал»: печатается промт, рядом из блоков собирается макет сайта |
| **Живое демо** | Поле «Опишите бизнес» → реальная быстрая генерация мини-превью за несколько секунд (облегчённый шаблон, без оплаты) |
| **Как это работает** | Закреплённая секция (ScrollTrigger pin): при скролле 4 шага сменяют друг друга, макет сайта «собирается» по слоям |
| **Портфолио** | Горизонтальный скролл карточек, наклон и параллакс при наведении, вместо картинки — видео-превью скролла сайта; клик открывает сайт с FLIP-переходом |
| **Сравнение** | «Студия: 60 000 ₽ и 3 недели» vs «GOAvito: 4 999 ₽ и 24 часа»: счётчики и шкалы анимируются при появлении |
| **Цена** | Карточка тарифа с 3D-наклоном и бликом, магнитная кнопка CTA |
| **Отзывы** | Бегущая строка (marquee) с инерцией от скорости скролла. **Только реальные отзывы** — до их появления блок скрыт |
| **FAQ** | Плавные аккордеоны (Motion) |
| **Финальный CTA** | Огромная кинетическая типографика, текст «растягивается» при скролле |
| **Глобально** | Плавный скролл (Lenis), кастомный курсор с реакцией на элементы, переходы между страницами (шторка или морфинг), шум/зерно поверх фона, тёмная тема по умолчанию |

### Производительность и доступность (обязательно)
- Цели: LCP < 2,5 с на мобильном, 60 fps, Lighthouse Performance ≥ 85.
- WebGL и тяжёлые эффекты загружаются лениво, а на слабых устройствах заменяются статичным градиентом.
- `prefers-reduced-motion`: при включённой настройке анимации заменяются плавными появлениями.
- На мобильных курсор и часть параллакса отключаются.

### Где смотреть референсы
- **Awwwards** (раздел «Sites of the Day» и коллекции по анимациям);
- **GSAP Showcase** и демо на **CodePen**;
- **Codrops** (Tympanus): готовые туториалы по WebGL-эффектам, переходам и типографике;
- **Godly.website**, **Land-book**, **Lapa Ninja**: подборки лендингов.

Перед вёрсткой собираем мудборд из 10–15 референсов и фиксируем дизайн-направление в `DESIGN.md` (шрифты, палитра, характер движения).

## 9. Портфолио, наполненное ИИ

- Каждая работа в портфолио — это **шаблон**: мы генерируем его по промту, дорабатываем руками до идеала и публикуем как пример.
- 10–15 работ на старте по популярным нишам: салон красоты, барбершоп, кофейня, ремонт, юрист, фитнес, стоматология, клининг, фотограф, автосервис, онлайн-школа, кондитер.
- **Подписываем честно:** «пример сайта, собранного GOAvito», а не «наш клиент». Выдуманные клиенты и отзывы нарушают закон о рекламе и подрывают доверие. Реальные кейсы добавляем по мере появления, с разрешения клиентов.
- Кнопка «Хочу такой же» на каждой работе ведёт в бриф с уже выбранным шаблоном.

| Бесплатные генерации без оплаты | Лимиты, вход по телефону, платная перегенерация |

| Тяжёлые анимации тормозят на телефонах | Бюджет производительности, ленивая загрузка, упрощённая мобильная версия |
| Ручная публикация не масштабируется | Этап 5: автопубликация через API хостинга |
